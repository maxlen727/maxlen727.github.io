## 走，到北京去

束束真的是个恋旧的人，自从开学之后每天都给高中的老同学电话交流。

没办法，实在没办法放下啊。正好 Tino 和 MinString 都在北京上学，所以束束就决定国庆假期去北京看看，见见这两位可爱的老友。

MinString 要先回家看看，所以到北京之后束束就先跟 Tino 一起行动。

和 Tino 玩得非常开心 ❤️ Tino 简直是大家长，束束每天带着个不清不楚的猫脑袋什么都不用想——不用关心接下来要去哪里，不用关心地铁该坐到哪一站，不用关心吃饭吃什么——抱着 Tino 的胳膊走就可以了。嘿嘿，真的令人安心呀 (´ω｀*) 请把一切的决策都放心交给 Tino 吧！

不过都是在北京二环附近和以内逛，饭是真的比较贵。但其实束束的价格观非常糟糕，一碗要 38 元的卤煮还挺让人犹豫的，但是束束直接对着店员说请来两份。看着 Tino 还在手机上研究点餐，束束开心地告诉 Tino 说不用看了，已经点过了哦（骄傲脸）。然而却被家长 Tino 批评了 (╥﹏╥) Tino 说手机上点只需要 32 元并且还买一送一 w(ﾟДﾟ)w 本来等夸奖的束束直接被挫败到耳朵耷拉了呜呜呜呜呜。以后还是听家长大人的话才好，完全蠢猫了呜呜呜呜呜呜呜呜。

就是晚上和 Tino 同床共枕还是有些心心不平，睡得比较差。但是这种感觉倒是很幸福，可以拉手手和抱抱（唔，这样真的好吗(〃ﾉωﾉ) 

后来 MinString 也加入了我们，就三个人又一起玩了两天。MinString 还带束束逛了逛清华园，不愧是清华啊——作为学校，里面的基础设施真的非常好，印象深刻的就是有一个装修的非常 lofi 的木屋，让人进去就想 Flow, 里面也有很多学生在读书或者 Coding. 作为园子，清华非常美丽，澄明的湖与荫蔽的树相得益彰，果然“水木清华”。

别离的时候不出所料，束束又哭了。Tino 细心叮嘱了束束应该坐哪一路，怎么换乘，到哪一站（果然是完全当小孩对待了吧），分开那一刻束束才意识到：啊，我们短暂的相处又结束了啊，下次...下次可能就是寒假了。让束束整个地铁过程上泪流不止...

相见时难别亦难，东风无力百花残

## 受宠若惊的面试

束束平时喜欢坐在「暮歌」这园子的长椅上休憩，但是最近似乎来访的客人有点多了，束束经常被惊醒呢~

咳咳，是这样的：束束想要参加一个技术社团，需要参加面试，准备的面试表需要写个人能力相关的条目。束束这些年净喜欢折腾些没用的东西，而也没能想到他们在此刻会发挥用场：5 年 Linux 桌面使用经验、Github Heatmap Plus 这个 DMS 插件的开发、「诗文社的学生」这个视觉小说项目、《ArchLinux 简明指南》的编写工作......还有一些杂七杂八的小零碎的能力，比如 AI Agent 经验，Github、Vercel 一类平台的使用经验......

这些以前所做过的“没用”的折腾让束束成了同学口中的“大佬”。唉唉，束束可实在担不起这个称号。据面试官们说束束的面试表已经被传开了，有一些别的社团的负责人都想见见我。至于束束的 Github、社交媒体账号和「暮歌」这片园子也已经被前辈们看光光了 (,,・ω・,,)

但是收获这么多关注真的让束束受宠若惊，因为束束不认为自己是多么厉害的人，自己也离“大佬”有很长很长的距离。束束根本不配得到这么多关注，所做的工作也仅仅是一些连雕虫小技都算不上的东西罢了。自己也是很惭愧，毕竟接触了这么久的电脑，完全可以认真钻研一门编程语言或者一些底层的技术栈的，但是直到如今也没有深透任何技术，仅仅是一个广泛涉猎的“外行人”罢了。

## 为什么我讨厌 Omarchy

接上一条面试的事情，在面试的时候束束被问及是否尝试过 Omarchy.

呃，抱歉听到这个词让束束打了个哆嗦——束束在面试时直接竖起了中指并表示自己鄙弃这个发行版，但束束看见面试官脸上似乎露出了一丝丝不解。那让我们来一起端详一下 Omarchy 这个万花筒吧。

Omarchy, 就当我们才刚刚初见吧。现在假设某猫耳娘从来不知道 Omarchy, 在 X 上闲逛时发现 Omarchy 成为了最近的潮流，于是打开了 [Omarchy 的官网](https://omarchy.org/)想要看看它到底是什么东西。

> Beautiful, fun & agentic Linux by DHH

> The malleable OS for the age of agents. Vibe your way through every alteration, tweak, or trouble.

Agentic Linux...吗？呃......各位，各位，比 Agentic OS 的美好幻想先来到束束脑子里的是一股子营销气味。但或许这只是 AI 时代下对于人们爆炸宣传造成的 Hype Fatigue. 它到底是个什么东西，束束还需要接着去看——

继续往下翻动官网，对于 Agentic OS 的解释是，此系统内置了一些 Agent 工具和 SKILLS 帮助你塑造你的系统。同时看着官网上几张截图，束束隐隐能看出来这是一个使用了 hyprland 以及大量自定义配置的“发行版”。

嗯......“发行版”？好吧，好吧...其实与其说它是一个发行版，在束束眼里，它更像是一份 dotfiles.

那我们看看[它的 Github 仓库](https://github.com/omacom/omarchy/)里到底放了什么吧——最抓眼的无非是 `agents/skills`, 这个文件夹下的 skills 都是在教 Agent 们怎样去塑造这个系统。不看这些 skills 了，还有一些更让束束在意的点：

```lua
-- default/hypr/bindings/applications.lua

  o.bind("SUPER + SHIFT + E", "Email", { webapp = "https://app.hey.com" })
  o.bind("SUPER + SHIFT + ALT + E", "New email", { webapp = "https://app.hey.com/messages/new?display=standalone&new_window=true" })

```

Hey? What's this?

Hey 邮箱，刚上线的时候束束就听说过它，印象里似乎是个蛮不错的产品呢！束束本可不去深究这个配置的，但是上下文中别的快捷键绑定大都是 Google 系和 X 的一些服务，怎么此处突然出现一个 Hey 呢？啊，束束似乎想起来了之前听过的一期播客：[「Hey! 你试过 Hey 了没？」](https://anyway.fm/hey-app/)

> 必须要从这家以前叫 37signals 现在叫 Basecamp 的公司说起
> 他们的联合创始人 David Heinemeier Hansson......

原来是这样啊...（长嘘一口气）诸位拾星者们，这下你们看出什么端倪了吗？ (;¬_¬) 束束完全可以怀疑这就是在刻意地夹带自己的产品私货。

以及束束在翻阅 DHH 的 blog 时看见了他对 XPS 的盛赞： [「Dell is on a roll with the XPS」](https://world.hey.com/dhh/dell-is-on-a-roll-with-the-xps-5a09a84e)

然后就在 Omarchy 的仓库里发现了 `default/audio/tunings/dell-xps-2026`

是的，束束几乎可以认为：作者主力电脑的调优配置被 Omarchy 上游化了。

且不讨论给发行版塞个 Agent 和一些 skills 是否有技术壁垒，**这个发行版，或者说这份 dotfiles, 从头到尾都充满了 DHH 的个人色彩**。这到底是一份面向 AI 时代的大众发行版，还是 DHH 这位科技巨星的“孤独摇滚”？DHH 所强调之 「malleable」, 最后分发出来的就是一份已经被 DHH 塑造过的系统吗？

其实从一开始束束就对发行版介绍里的「 by DHH 」十分在意，现在是时候了解一下 DHH 其人了。

DHH, 无疑他是一位传奇人物。无论是大胆使用 Ruby 的技术眼光，还是 Rails 范式对 Web 开发的重新定义都证明他是一位好的科技领袖；对 VC 、云服务厂商和苹果税的反抗展现了他个人的品味坚持......

看看 B 面吧。

DHH 的 blog 上技术分享和政治文章掺半。束束反感技术圈（尤其还是个做开源的）的意见领袖输出政治观点，这似乎破坏了束束对于“技术没有国界，开源不谈政治，社区多元包容”的美好想象。

并且 DHH 的对于政治的看法是否有些...过激？

[「As I remember London」](https://world.hey.com/dhh/as-i-remember-london-e7d38e64)

DHH 在文章里怀念过往记忆里的伦敦，90年代的伦敦在他看来才是安全、体面、文明的。这篇不免让束束想到了最近上的一些社会学相关的课程里，老师提到关于“现在的社会是否就是如某些人所说的越来越差”，具体到例子上：现在的人越来越不文明了，火车高铁上外放的，乱扔垃圾的！然而真的与以前的火车对比，以前的火车可并非都是影视中的美好景象，吸烟吐痰地上睡觉的，其实才是真的普遍现象——就是因为现在的人越来越文明了，某不文明案例才会让人感觉到不文明；现在的邻里关系越来越差了，住隔壁都老死不相往来的！然而发语者所提的以前，大概是鸡犬相闻的乡村邻里，而随着城镇化，邻里关系的结构早已发生了变化。现象上是邻里关系变差了，但是本质其实已经转移......束束想 DHH 的看法是否也是陷入了这样的片面呢？作为一个早已拥有大量财富的人，他只关心上层的生活，忽略了以往下层的苦难。而这怎么能是简单的“进步主义软弱”和多元主义的空洞呢？

DHH 反对多元主义与反觉醒这件事，也许在 [2021 年的 Basecamp 事件](https://www.theverge.com/2021/4/30/22412714/basecamp-employees-memo-policy-hansson-fried-controversy)中就有体现了： DHH 并非少数族裔，也不是 LGBTQ+ 群体，他是一个身居高位的利益享受者，自然不会在意对于这些多元文化真正有需求的人。

（呕吐）为什么要谈这些，怪束束开了这个头，我真的不想扯上这些意识形态与政治文化的事情。

好了好了，目光回到 Omarchy. 要束束如何评价它呢？如果它是个老老实实的仓库，本分地躺在互联网角落里分享着自己的 dotfiles, 那么束束可能会给它一个 star 并尝试一下这份美丽的 dotfiles. 但可惜了，Omarchy 一点也不像一个老实的东西。

[「American hype」](https://world.hey.com/dhh/american-hype-6f7afd1b)

看看 DHH 这篇文章吧，他就是支持这种“美国式炒作”。所以为什么要谈什么 [「The malleable computer」](https://world.hey.com/dhh/the-malleable-computer-7c187a9b) 和 「Agentic OS」呢？也许就是为了炒出来一个美妙的故事吧。

Omarchy 需要讲这么一个故事，毕竟它背后还有 37signals 这家商业公司。商业，商业。 Omarchy 就是 DHH 这家公司未来的三年。

[「All-in on Omarchy at 37signals」](https://world.hey.com/dhh/all-in-on-omarchy-at-37signals-68162450)

Omacom(Omarchy 的基金会) 拿了多少钱呢？1800 万美元？但是谁知道呢？因为[这份赞助者名单](https://omarchy.org/patrons/)可能还会继续增加。

其实这才是 Omarchy 让束束感到最不适的地方：作为一个下游的方案整合商，因为一个「Agentic OS」的叙事拿到了大量的资金支持。而上游的基础设施们，比如 Hyprland、Quickshell、Arch Linux 云云却没有得到资本们的支持。也是，毕竟你看， 「Modern compositor with the looks」 和 「Beautiful, fun & agentic Linux by DHH」 哪个听起来更诱人一些？不过束束就是厌烦这套，凭什么上游得不到支持，而你仅凭一个美好的故事就得到了巨量的资金呢？

Omacom 也拿出了一部分钱资助 Hyprland 和 Quickshell 云云，束束并不认为值得夸赞，这本就是应该的事情。但此处还有一个问题： Hyprland 的主要开发者已经完全被 Omacom 包养了，那么这套技术决策话语权真的还能放在社区手里吗？ Omarchy 是否对 Hyprland 有了更多更多的控制权呢？另外最重要的上游 Arch Linux 和各种 cli 工具的开发者们为何没有收获到 Omacom 的赞助呢？想到这里，束束更加阴谋地怀疑 Omacom 的捐赠行为仅仅是做做样子，并顺带获取对 Omarchy 关键的项目的话语权罢了。再吸口开源社区的血，然后拿出巨量的赞助中的一小部分“回馈”回去...

咳咳，抱歉有些激动了......似乎这些猜想有些疯狂了......

束束想说： Omarchy 就是德不配位。

我不会给它 star (虽然束束的 star 对它无关紧要)，也不会去尝试它。

## 关于风格化写作

之前就来过「暮歌」的拾星者们可能发现束束的文风发生了一些变化，包括过往的文章似乎也都被改造了呢。

包括开始自称“束束”，称读者为“拾星者”，称本站为“园子”，期望是展现一种柔和的风格，并使文章变得有些可以玩味。

总体上来说，还是让束束很满意的。这是一个长期决定，因为随着文章增多，如果再想更改文风那就要还“文债”了。所以请大家允许我这个站长装装可爱卖卖萌吧（欸嘿）

怎么想到束束这个名字呢？是我的小名了。也许父母希望我可以不偏不倚地成长吧，成为一个规范规矩的孩子。但“束束”也只是我想象的啦，因为我只知道音节是这样，但万一是“术术”呢？嘿嘿，不乱想了，反正我就是束束啦！

设定上应该是这样的猫耳娘呢，还是感谢 GPT 大人了！
