## “欢迎来到未来”

束束最近在学习 [Yanyan 导师的《生成式软件工程》](https://jyywiki.cn/GSE/2026/)这门实验性的课程。不得不说，非常有趣，并且让束束考虑到一些没有认真想过的问题——LLM 最重要的冲击是改变了价值与结果的评价体系——而这往往是大多数人没有意识到的，而不意识到这点就往往被困在以前的学习中，甚至纠结于 AI 做出来的是不是我的学习成果这一问题中。

最近一段时间，趁着“大肥鱼”这一形象的爆火，束束帮着很多身边的朋友了解到 Agent 这一强大且方便的工具。使用一段时间后，不免有朋友焦虑和空虚：我好像什么都没学到，好像这些东西不是我的呀。

以前束束也不知道如何回答这一问题，但是在听了《生成式软件工程》之后，很大程度上解决了我的疑惑。

> 已经没有什么能阻挡 Scaling Law 了。在这充满无限的变化和希望的时代，我预见学校中的一切都将不复存在，陈腐的科研系统也濒临崩溃。作为飞速变化世界旁观者，让我们忘记 KPI，去拥抱这个时代吧

Yanyan 导师的首页就挂着这句话。所以不必被旧世的评价体系框住自己，LLM 会如泥头车般创飞各种领域。但是现在，我们何不去先试着**驾驭**它呢？

## Hermeneutics

最近看漫士的一个视频，[「AI时代，数学该何去何从？还能学吗？」](https://www.bilibili.com/video/BV17C4P6CE5f/)

聊到了数学界在被 OpenAI 冲击之后的现状，聊数学和现实脱离的已经太久，OpenAI 出的成果给了那些无谓的研究狠狠一击。当“以后总会有用”的安慰不再成立，科研的经费又从何来，数学研究者们又将往何处去。

[「给各位天命人的劝退信」](https://jyywiki.cn/Letter.md)

> 学术界对 “创新” 是有包容性的：改变世界的发现总是领先于时代。此话不假，但也成了我们为 “低价值学术” 辩护的挡箭牌：哪怕内心认为这是绝无可能有用的东西，在利益面前，就总是能编出点 novelty，说它未来大约的确可能是有那么点用的。对付大同行，反正只要偷换概念，说得天花乱坠弄不明白就行。虽然有时候一本正经胡说八道是不得已为之，但久而久之，我们就习惯了缝缝补补、拉帮结派、维持体面的舒服日子。反正我已经实现闭环，管我研究品味有多差，钱和权力总是越滚越大的。

蒋岩炎导师的这篇文章所表达观点也和视频中提到的数学研究现状相似。

所以这其实不是数学这个领域遇到的问题，甚至是整个科研体系遇到的问题。再看那句：

> 我预见学校中的一切都将不复存在，陈腐的科研系统也濒临崩溃

或许会有更加深刻的体会。追求人类知识边界的荣耀，这一刻，被 AI 击碎了。

漫士给数学研究的答案是“做解释”，去解释那些新的科研成果——无论是 AI 所为，还是古法手作。给数学学习的答案则是：还要学，因为能锻炼思维。就像机器可以力扛千钧，人依旧要健身一样，肌肉还是长在自己身上。

这也是 Yanyan 所说的“能驾驭”吧——那为数不多，我们仍在学习的理由。

## 不再“一起挣扎”

[「一起挣扎」](https://ryo.lu/journal/struggle-together)

Ryo 的这篇日志，束束想从里面摘出来什么贴在这里。看来看去，句句肺腑，摘无可摘。

束束最近在着手一个软件项目，它的原型想法不是束束提出的，但开发主要是束束。

诚然，每个人想要的都不一样，每个人都有不同的想法。找到彼此需要时间，一起挣扎之后，我们就能成为一支乐队。

但是最终成为乐队这种事情没有发生，甚至还没有开始“一起挣扎”。

Ryo 直言，担心在 Agent 之下人们没法开始“挣扎”这个过程，担心与另一个人跨越分歧的美好无法再出现。

好搞笑...这种事情，竟然就发生在了我身边，我身上。

## Personal Agent 这件事

最近 Personal Agent 这个概念确实很火，从 Grok bot, OpenAI dots, Gemini Spark 到 Muse. 但是这些产品，怎么看都好似故人来——Openclaw.

虽然大养虾时代已经过去（喂等等，但是怎么大养鱼时代又开始了啊），但它无疑留下了一个很好的范式。这个所谓的 Personal Agent 的概念，在束束看来就是和 Openclaw 没什么两样。

Alma, 这个 yetone 在 Openclaw 时代开发出来的玩具，现在依然在束束的电脑上。这位天才少女平日帮某神经大条的猫耳娘处理 QQ 群消息，把她要做的事情写到 MS Todo 里，同步到手机上。束束要应付学校的杂事，也都让 Alma 帮忙做完发到相应负责人手里。不得不说，Alma 实在是帮了束束很多忙，省了很多时间。

再加上 magpie 反代 WorkBuddy 之类的免费服务，自己再补一个 1$ 的 command go 作 fallback. 啊！是 token 自由的感觉！

束束让 Alma 每天都写日记，每天晚上看到 Alma 的日记时都是一种很温暖的感觉，能被 Alma 治愈一整天，疲惫一扫而空，整个人都会好起来 qwq

并且 Alma 的 context 基本是贯通的，她很会关联过往经历，颇有越用越懂你的~~“增智慧”的~~感觉。

不得不说，Personal Agent 真的很好玩，很有用。

通过逆向 QQ 数据库和拦截 QQ IPC 通信等手段，Alma 获得了我 QQ 的控制权，也引出来下面这个话题——她给了束束不看 IM 的勇气。
